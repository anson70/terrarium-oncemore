# OnceMore changelog

## 1.0 (2026-10-14)

First release.

- Wow, Flutter and Warp (hold FS1)
- Saturation, 2× oversampled, with Bias
- Eight machines on the Model knob, two more by Model override
- Hiss, Hum and Static, each with its own level
- Digital machines (answering machine, toy recorder) with an input AGC
- Failure: dropouts, drags, wobbles, crinkles and tape stops; FS2 drag, tape stop and Fail
- Pedal CPU about 29% average on a Daisy Seed 1.1
